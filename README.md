This is a rework of jwueller's Jellyfin one pace plugin found here: https://github.com/jwueller/jellyfin-plugin-onepace  
  
This project uses the onepacerr API for retrieving One Pace metadata rather than the now defunct One Pace API. This plugin populates series, season, and episode metadata like the original plugin. 
However, the metadata from the onepacerr API is only available in english (meaning there are no localization options), and no image data is available.  

  For installation, unzip the released zip file into the jellyfin plugins folder
